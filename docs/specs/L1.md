# ReflectQ — L1 Requirements

| ID | Requirement |
|----|-------------|
| L1-01 | **QR Code Display / Presenter View** — The presenter view shall display a QR code, question text, and live response counter in a full-screen-friendly layout. |
| L1-02 | **Response Collection / Respondent Page** — The respondent-facing mobile page shall present a question with the appropriate input control and a submit action. |
| L1-03 | **Real-Time Feedback Dashboard** — The admin dashboard shall visualise incoming responses in real time with list, chart, and summary views. |
| L1-04 | **Question Management** — The admin application shall provide screens for creating, editing, activating, archiving, searching, and sorting questions. |
| L1-05 | **User Management** — The admin application shall provide screens for inviting, editing, deactivating, and listing admin users with roles. |
| L1-06 | **Authentication Flow** — The admin application shall include sign-in, sign-out, and session-management UI using OAuth2. |
| L1-07 | **Responsive & Accessible Layout** — All screens shall adapt to mobile, tablet, and desktop breakpoints and meet WCAG 2.1 AA guidelines. |
| L1-08 | **Question Management API** — The backend shall expose RESTful endpoints for creating, reading, updating, activating, archiving, searching, and sorting questions. |
| L1-09 | **Response Collection API** — The backend shall expose a public endpoint for submitting responses and persisting them. |
| L1-10 | **Real-Time Response Streaming** — The backend shall push new responses to connected clients in real time via SignalR. |
| L1-11 | **User Management API** — The backend shall expose endpoints for inviting, editing, deactivating, and listing admin users with role-based access. |
| L1-12 | **Authentication & Authorization** — The backend shall authenticate requests using JWT bearer tokens and enforce role-based authorization. |
| L1-13 | **Data Persistence** — The backend shall use Entity Framework Core with SQL Server for all data persistence with migrations. |
| L1-14 | **Presenter View Components** — The components library shall provide reusable presentational components for the presenter view: AppLogo, QrCodeFrame, ResponseCounter, and FullScreenButton. |
| L1-15 | **Respondent Components** — The components library shall provide reusable presentational components for the respondent pages: OptionCard, StarRating, SubmitButton, QuestionText, TextAreaField, and ConfirmationMessage. |
