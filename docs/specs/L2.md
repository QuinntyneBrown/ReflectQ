## L2-08 · Question Management API (traces to L1-08)

| ID | Requirement | Acceptance Criteria |
|----|-------------|---------------------|
| L2-08.1 | GET /api/questions shall return a paginated list of questions with search and sort support. | AC1: Returns 200 with paged results. AC2: Supports `search`, `sortBy`, `sortDirection`, `page`, `pageSize` query params. AC3: Default excludes archived unless `includeArchived=true`. |
| L2-08.2 | GET /api/questions/{id} shall return a single question with its options. | AC1: Returns 200 with the question. AC2: Returns 404 for unknown id. |
| L2-08.3 | POST /api/questions shall create a new question. | AC1: Returns 201 with Location header. AC2: Validates required fields (title, type). AC3: Returns 400 for invalid input. |
| L2-08.4 | PUT /api/questions/{id} shall update an existing question. | AC1: Returns 200 on success. AC2: Returns 404 for unknown id. AC3: Returns 400 for invalid input. |
| L2-08.5 | PUT /api/questions/{id}/activate shall set the question status to Active and deactivate any currently active question. | AC1: Returns 200. AC2: Only one question is active at a time. |
| L2-08.6 | PUT /api/questions/{id}/archive shall set the question status to Archived. | AC1: Returns 200. AC2: Archived questions are excluded from default listing. |

## L2-09 · Response Collection API (traces to L1-09)

| ID | Requirement | Acceptance Criteria |
|----|-------------|---------------------|
| L2-09.1 | POST /api/responses shall accept a response with questionId and value. | AC1: Returns 201 on success. AC2: Validates that the referenced question exists and is active. AC3: Returns 400 for invalid input. |
| L2-09.2 | GET /api/questions/{id}/responses shall return all responses for a question. | AC1: Returns 200 with a list of responses ordered by timestamp descending. |
| L2-09.3 | DELETE /api/questions/{id}/responses shall clear all responses for a question. | AC1: Returns 204. AC2: All responses for the question are deleted. |
| L2-09.4 | GET /api/questions/{id}/responses/export shall return responses as a CSV file. | AC1: Returns 200 with Content-Type text/csv. AC2: CSV includes columns: ResponseId, Value, SubmittedAt. |
